# Проверка P3 через Unity MCP

Проверка выполнена 03–04.11.2026 в Unity 2022.3.62f3 по прямому поручению пользователя. Использованы Unity Test Runner и обычный Play Mode через Unity MCP. Исходная открытая сцена Gameplay была сохранена; после проверки восстановлена вне Play Mode.

Покрыты правила P1/P2, сохранённые привязки и коллайдеры, свободная орбита и кадрирование, распознавание жестов, выбор ближайшей обращённой головки, препятствия, полный записанный W, удаление только завершённых владельцев и логическая победа с пустым пулом. BootstrapPipelineTests проверяет Bootstrap → Gameplay, restart и прямую загрузку Gameplay.

Первый EditMode-прогон выявил два дефекта тестовых данных RouteReaderRejectsDamagedWitness: Newtonsoft.Json отклонял обязательные null при сериализации до вызова reader. Тест теперь сначала создаёт корректный JObject, повреждает входной JSON и проверяет исключение только от reader. Повторный полный прогон: 262/262.

Первый общий PlayMode-job потерял состояние после перезагрузки домена и не дошёл до тестов. Зависшее задание MCP очищено; три сборки успешно выполнены отдельными запусками. Это сбой запуска инструмента, а не падение теста проекта.

## Дополнительная проверка работающего Gameplay

Обычный запуск Bootstrap автоматически открыл Gameplay. Через штатные BeginPointer/UpdatePointer выполнены синтетические жесты; аппаратный Input.GetTouch этим не проверялся. Успешны девять проверок:

1. Тап по настоящей головке выдаёт ровно один Selected с нужным ID.
2. Настоящие EventSystem, Canvas, Image и GraphicRaycaster блокируют выбор через UI.
3. Drag вращает камеру без выбора болта.
4. Выход из viewport отменяет тап.
5. Потеря фокуса отменяет тап.
6. UI, начавший блокировать лучи во время жеста, отменяет выбор при отпускании.
7. Указатель с finger ID и повторное отпускание дают ровно одно событие.
8. Два полных оборота по каждой оси возвращают исходную позу.
9. Обычный выбор сохраняет все девять болтов и четыре детали активными.

Временные UI-объекты удалены после проверки. При создании UI ожидался кадр регистрации графики перед raycast: до первого кадра Image.depth=-1 и графика ещё не участвует в GraphicRaycaster.

## Исправление освещения и осмотр

На снимке работающей камеры задняя сторона была почти чёрной: Skybox ambient сцены не давал заметной подсветки при одном Directional Light. В RenderSettings сохранённого Gameplay установлен AmbientMode.Flat и нейтральный ambientLight=(0.45,0.45,0.45,1). Новые источники света, компоненты, изменения мешей и материалов не потребовались.

После сохранения повторно выполнен BootstrapPipelineTests: 1/1 Passed. При новом запуске из сохранённого Gameplay проверены Flat/0.45 и видимость головок сзади и в перевёрнутом положении камеры. Снимки сохранены локально в Screenshots/P3Verification; каталог исключён из Git. После проверок Console не содержит ошибок или предупреждений.

## Что ещё требует подтверждения

Проверка подтверждает работу в Editor на текущей конфигурации. Не проверены физические касания и multitouch, производительность на Android и удобство на экране устройства. Ручная оценка допустимой погрешности примитивов у краёв/просветов и удобства управления остаётся за пользователем. Gate P3 не закрыт одним автоматическим прогоном.
