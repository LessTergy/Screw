# Проверка первого отображения шейдеров в Unity Editor

Unity 2022.3 может на короткое время показать ярко-голубую заглушку, пока компилируется нужный вариант шейдера. Для проверки сравни первый запуск после очистки с повтором того же действия. [Асинхронная компиляция в Unity 2022.3](https://docs.unity3d.com/2022.3/Documentation/Manual/AsynchronousShaderCompilation.html)

1. В Edit Mode открой `Bootstrap`, переключись на вкладку Game и сними выделение с материалов в Inspector. Так Scene View и предпросмотр материалов с меньшей вероятностью скомпилируют нужные варианты до проверки.
2. Проверь, что в **Edit → Project Settings → Editor → Shader Compilation** включена **Asynchronous Shader Compilation**.
3. Выбери **Tools → Screw → Rendering → Clear Shader Cache**. Дождись сообщения `Cleared editor shader cache` в Console. Если идёт компиляция, дождись её завершения и повтори команду.
4. Полностью закрой Unity Editor и снова открой проект на `Bootstrap`. Сразу нажми Play, затем **Играть** или **Продолжить** в главном меню. Проверь первые кадры Gameplay. Если вспышка возникает при первом удержании модуля, один раз активируй просветку. Запиши, какой объект стал голубым и при каком действии.
5. На версии с prewarm первый кадр модели и первая просветка должны сразу показывать свои материалы. Повтори холодную проверку несколько раз и сравни с запуском без очистки. Нажми **Ⅱ → Заново** и проверь перезапуск уровня.

Если Console сообщает, что кэш занят или Unity успела его создать заново, закрой Editor, удали папку `Library/ShaderCache` проекта и продолжи с шага 4. Unity пересоздаёт эту папку при компиляции вариантов. [Кэш компиляции шейдеров в Unity 2022.3](https://docs.unity3d.com/2022.3/Documentation/Manual/shader-compilation.html)

При переходе из `Bootstrap` камера Gameplay рисует два кадра во временную текстуру перед первой видимой отрисовкой. Первый кадр прогревает обычные материалы, второй использует полупрозрачный материал на мешах модели. Прогрев охватывает проходы камеры и её стека для стартовой сцены. В Editor компиляция во время этих двух проходов синхронная, поэтому холодный запуск может занять больше времени. [Загрузка и прогрев шейдеров в Unity 2022.3](https://docs.unity3d.com/2022.3/Documentation/Manual/shader-loading.html#prewarming-shader-variants)
